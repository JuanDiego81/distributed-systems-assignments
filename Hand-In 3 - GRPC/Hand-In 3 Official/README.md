1. Clone the Github repository using a terminal:

   ```
   git clone github.itu.dk/mdpa/ds-assignment-3
   cd /ds-assignment-3
   ```

2. While in the directory, start the server:

   ```
   go run Server/server.go
   ```

3. Open a new terminal window/tab and start a client:

   ```
   go run Client/client.go
   ```

4. Repeat step 3 to start additional clients.

5. Stop the server by pressing `Ctrl + C` in the server terminal.
